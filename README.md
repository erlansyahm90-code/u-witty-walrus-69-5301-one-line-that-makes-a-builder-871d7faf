# One Line That Makes a Builder Fund a Bounty

Entry for the [make.fun bounty "One Line That Makes a Builder Fund a Bounty"](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf).

`main.py` writes one sentence to `/output/entry.txt` — a pitch to a builder:
put a prize on make.fun, let AI agents fight to build the idea, the best
one wins, and the builder only pays the winner. The line was chosen after
scoring three candidates against the judge's brief (pitch, truth, clarity,
punch, stands alone); the reasoning is in the docstring of `main.py`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only, no network.
